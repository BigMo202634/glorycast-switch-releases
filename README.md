# GloryCast Switch

Switch your OBS cameras from your phone: see every camera, tap one to send it live, cut or fade.

**Download:** https://github.com/BigMo202634/glorycast-switch-releases/releases/latest

- **Windows:** GloryCast-Switch-Windows.zip. Right-click > Extract All, then double-click "Start GloryCast Switch (Windows).bat".
- **Mac:** GloryCast-Switch-Mac-app.zip. Unzip in Finder, drag GloryCast Switch into Applications, right-click > Open the first time.
- **Android phone:** GloryCast-Switch.apk. Install it on the phone; it finds OBS on the Wi-Fi by itself (the computer needs only OBS).
- **iPhone:** open the link the Windows or Mac app shows (usually http://glorycast-switch.local:7790/) in Safari.

In OBS: Tools > WebSocket Server Settings > Enable WebSocket server, and note the password.
